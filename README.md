# Disney+ Experience Clone

A responsive Disney+ inspired interface built to practice cinematic layouts, dynamic content, routing, and polished media interactions.

## Features

- TMDB-powered movie and series data
- Branded collection and title pages
- Dynamic routes and episode views
- Persistent guest My List
- Responsive navigation and layouts

## Built With

- React
- Vite
- JavaScript
- TMDB API

## Requirements

- Node.js 20 or newer
- npm

## Installation

```bash
git clone https://github.com/Miingo954/disney-plus-clone-react.git
cd disney-plus-clone-react
npm install
```

## Run Locally

```bash
npm run dev
```

Open the local URL shown in your terminal.

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
